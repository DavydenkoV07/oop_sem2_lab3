# Аналізатор частоти слів (Lab 3 - OOP)

Цей проєкт розроблено в рамках Лабораторної роботи №3 ("Паралельне мультипоточне програмування") з дисципліни "Об'єктно-орієнтоване проєктування" (2026). 

Програма аналізує великі обсяги текстових даних та підраховує частоту появи кожного слова. Головна мета — продемонструвати різницю у швидкодії між однопотоковим (послідовним) та багатопотоковим (паралельним) підходами до обробки даних.

## Основний функціонал
- **Послідовний аналіз:** Опрацювання тексту в одному потоці (еталон для порівняння).
- **Паралельний аналіз:** Використання `Parallel.ForEach` та `ConcurrentDictionary` для безпечного розподілу обчислень між ядрами процесора без стану гонитви (race conditions).
- **Асинхронний GUI (WPF):** Запуск важких обчислень у фоновому потоці (`Task.Run`), завдяки чому графічний інтерфейс не блокується під час роботи.
- **Бенчмаркінг:** Вимірювання та виведення часу виконання алгоритмів за допомогою `Stopwatch`.

## Технології та Архітектура
- **Мова та Платформа:** C#, .NET
- **Графічний інтерфейс:** WPF (Windows Presentation Foundation)
- **Тестування:** NUnit
- **Документація:** Doxygen
- **Патерни:** Strategy (реалізовано через інтерфейс `IWordFrequencyAnalyzer`, що дозволяє легко перемикати алгоритми підрахунку).

## Структура рішення (Solution)
Проєкт розділено на три незалежні частини за принципом єдиної відповідальності (Single Responsibility Principle):
1. `WordAnalyzer.Core` — бібліотека класів із бізнес-логікою (алгоритми).
2. `WordAnalyzer.GUI` — графічний інтерфейс, що взаємодіє з користувачем.
3. `WordAnalyzer.Tests` — юніт-тести для перевірки точності паралельного алгоритму та крайових випадків.
